# 公文產生系統 v3

## v3 新功能
- 一鍵公文產生：首頁直接按常用範本。
- 範本管理：可自行新增、編輯、刪除公文範本，不必改程式。
- 範本變數：`{{工程名稱}}`、`{{受文者}}`、`{{月份}}` 等自動由專案帶入；自訂如 `{{廠商名稱}}`、`{{來文字號}}` 會自動變成填寫欄位。
- 保留自由建立公文、專案管理、歷史紀錄與 Word 匯出。
- Word 匯出指定標楷體，並加入裝訂線文字。

## 更新既有 Render 網站
將本 ZIP 解壓縮後的 `gongwen_deployable` 內容上傳到原 GitHub repository，Commit 後 Render 會自動重新部署。

> 注意：Render 免費方案若使用本機 SQLite，重新部署或休眠環境重建時資料可能遺失。正式長期使用建議改用 Render PostgreSQL 或其他持久資料庫。
